# Deploy OmniCRM AI to Vercel — One Command

## On your machine, run these 3 commands:

```bash
# 1. Login to Vercel (opens browser)
npx vercel login

# 2. Deploy to production
npx vercel --prod

# 3. Done! Your URL will be printed, e.g.:
#    https://omnicrm-ai.vercel.app
```

## That's it. Vercel auto-detects Next.js and handles everything.

---

## Alternative: GitHub Auto-Deploy

1. Push this project to GitHub
2. Go to https://vercel.com/new
3. Import your repo
4. Click "Deploy"
5. Every push to main auto-deploys
